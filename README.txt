# Jaswith Reddy — Professional Portfolio

This is a static, responsive portfolio website created from the resume supplied for this task.

## Files
- `index.html` — website content
- `styles.css` — visual styling and responsive layout
- `script.js` — mobile navigation and current-year footer
- `assets/resume.pdf` — copy of the supplied resume
- `assets/favicon.svg` — simple site icon

## Before publishing — important
1. Confirm all resume details are current and accurate.
2. Replace the generic GitHub, LinkedIn, and LeetCode links in `index.html` with your actual profile URLs.
3. Add project repository URLs if you have public repositories. The project cards currently do not pretend to have working repositories.
4. Confirm the IIT Madras B.S. program status and date shown in the resume are still accurate.
5. Review the project metrics (40%, 60%, 90%, 90%+) and be ready to explain how they were measured. They are included because they appear in the supplied resume.
6. Check that the resume PDF is suitable for public sharing before publishing it.

## Preview locally
Open `index.html` in a browser. An internet connection is needed to load the optional Google Fonts; the site remains usable without them.

## Publish using GitHub Pages
1. Sign in to GitHub.
2. Create a **public** repository named exactly `YOUR-USERNAME.github.io`, replacing `YOUR-USERNAME` with your GitHub username.
3. Upload `index.html`, `styles.css`, `script.js`, and the `assets` folder to the repository root.
4. Open the repository's **Settings → Pages**.
5. Under build and deployment, choose **Deploy from a branch**.
6. Select branch `main` and folder `/(root)`, then save.
7. Wait for the deployment to finish. The site URL will normally be `https://YOUR-USERNAME.github.io/`.
8. Open the published page in an incognito/private window and test the resume download, navigation, and every social/project link.

## Update the site
Edit `index.html` or `styles.css` on GitHub and commit the changes, or edit locally and upload the changed files. GitHub Pages will rebuild the site after the commit.

## Accuracy note
This website is based on the supplied resume and does not independently verify the claims in it. It intentionally uses placeholders where actual profile or repository URLs were not supplied.
